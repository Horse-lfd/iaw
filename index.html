Implementa Aplicaciones Web (IAW)

Descripción del módulo y competencias profesionales

En este submódulo se abordan las bases teóricas y prácticas para el desarrollo, diseño, configuración y despliegue de soluciones web modernas. El estudiante adquiere conocimientos sobre arquitecturas cliente-servidor, desarrollo frontend interactivo y buenas prácticas de maquetación semántica.

Competencias Desarrolladas

  • ▪ Diseño de interfaces atractivas, funcionales y accesibles.
  • ▪ Implementación de maquetación responsiva adaptable a dispositivos.
  • ▪ Programación de lógica e interactividad del lado cliente.

Tecnologías Clave

HTML5 CSS3 JavaScript Git & GitHub Servidores Web Flexbox & Grid
